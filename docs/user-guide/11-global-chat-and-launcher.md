# Global Chat and Launcher

Two auxiliary windows besides the main overlay — both open from the **system tray menu**.

## Global Chat

Standalone text chat window. **No screen capture, no Listen integration.**

| Aspect | Behavior |
|--------|----------|
| Open | Tray → **Global Chat** |
| Provider | Uses your configured chat provider and model from Settings → AI Providers |
| Accent | Uses the same accent color as the overlay (General → Accent color) |
| Use case | Quick text questions without meeting context or screenshots |

Global Chat maintains its own conversation thread separate from the overlay.

## Launcher

Compact control panel for session management and quick navigation.

| Control | Action |
|---------|--------|
| **Start Listen / Stop Listen** | Primary button — toggles the listening session |
| **Open overlay** | Shows the floating panel |
| **Settings** | Opens the settings window |
| **Recent sessions** | Last three session recaps with date and duration |

Open via **Tray → Launcher**.

The green dot in the header indicates when Listen is active.

## Tray quick reference

| Menu item | Window / action |
|-----------|-----------------|
| Open / Hide | Overlay toggle |
| Start / Stop Session | Listen toggle |
| Settings | Settings window |
| Launcher | Launcher window |
| Global Chat | Global Chat window |
| Start / Stop Phone Mirror | scrcpy mirror |
| Quit | Exit app |

Double-click the tray icon to toggle the overlay.
