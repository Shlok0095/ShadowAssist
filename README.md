# ShadowAssist

Windows desktop overlay for live meeting help (BYOK). Source and docs live in **`shadowassist-electron/ShadowAssist/`**.

- **App & build:** `shadowassist-electron/ShadowAssist/` — `npm ci`, `npm run dev` / `npm run dist:release`
- **Marketing site:** `shadowassist-electron/ShadowAssist/landing/` — `npm ci`, `npm run build`

CI workflows in `.github/workflows/` use those paths.
