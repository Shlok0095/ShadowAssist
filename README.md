# VeilAssist — Windows overlay

Desktop app and marketing site live under **`shadowassist-electron/ShadowAssist/`** (repo folder name is legacy).

- **Marketing site (Vercel):** `landing/` — `npm ci`, `npm run build` — deploy at **veilassist.vercel.app**

CI workflows in `.github/workflows/` use those paths.
