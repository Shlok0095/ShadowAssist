Bring your own API keys

ShadowAssist never embeds Groq, OpenAI, or NVIDIA credentials. On first launch you must accept legal acknowledgments, enter a key from your account, and pass a connection test. That keeps usage aligned with provider programs and your employer’s policies.

  • Keys stay in your Windows user profile (encrypted where the OS allows).
  • Uninstall or “delete all data” in Settings removes stored secrets from this app.
  • If you reused an old profile folder, you may still see prior keys — that’s your machine, not the installer.

First launch checklist

  1. Legal consent — all checkboxes required.
  2. Choose provider and paste your API key.
  3. Tap Test until it succeeds.
  4. Confirm BYOK acknowledgments, then start.

FAQ

Are API keys included in the download?
No. The app ships without vendor keys. You must supply your own. If you see a key after install, it was saved earlier on this PC or restored from backup — not from us.
Is this “undetectable”?
The UI is designed to be discreet. We don’t guarantee others can’t infer assistant use; follow your org and platform rules.
Where is data processed?
Requests go to the AI provider you configure. Read privacy and in-app terms.
Why does SmartScreen warn?
New or unsigned Windows builds are often flagged. Prefer signed releases when available; verify SHA256SUMS.txt on the release.
