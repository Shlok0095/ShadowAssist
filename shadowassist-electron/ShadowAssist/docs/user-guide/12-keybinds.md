# Keyboard shortcuts

All shortcuts are **global** (work while other apps are focused) and **customizable** in **Settings → Keybinds**.

Defaults below use **Ctrl** on Windows (shown as `Ctrl`; macOS builds would use `Cmd`).

## Overlay visibility

| Action | Default |
|--------|---------|
| Show / hide overlay | `Ctrl+\` |
| Hide overlay | `Escape` |
| Focus overlay input (stealth typing) | `Ctrl+Shift+T` |
| Open settings | `Ctrl+Shift+S` |

## Ask AI

| Action | Default |
|--------|---------|
| Ask AI with screen (vision + audio/text) | `Ctrl+Enter` |
| Ask AI without screen (audio/text only) | `Ctrl+Shift+Enter` |
| Clear chat / session buffer | `Ctrl+R` |
| Copy last assistant reply | `Ctrl+Shift+C` |

## Listen session

| Action | Default |
|--------|---------|
| Start / stop listening session | `Ctrl+Shift+\` |

## Capture and navigation

| Action | Default |
|--------|---------|
| Capture screenshot (queue) | `Ctrl+H` |
| Nudge overlay up | `Ctrl+Up` |
| Nudge overlay down | `Ctrl+Down` |
| Nudge overlay left | `Ctrl+Left` |
| Nudge overlay right | `Ctrl+Right` |
| Scroll answers up | `Ctrl+Shift+Up` |
| Scroll answers down | `Ctrl+Shift+Down` |

## Customizing

1. Open **Settings → Keybinds**.
2. Click a row and press your desired key combination.
3. Conflicts show a warning — pick a unique combo.
4. **Reset to defaults** restores the table above.

Some shortcuts (like `Escape` for hide) may feel natural to keep unchanged during live meetings.

## Input bar reminders

The overlay input shows inline hints:

- `Ctrl+Enter` — ask with screen
- `Ctrl+Shift+Enter` — ask without screen
- `/skill-name` — invoke a skill
